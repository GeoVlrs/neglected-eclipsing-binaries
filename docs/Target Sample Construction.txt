Following the automated selection run of Script 01 against the full Kreiner (2004) catalogue, the output file neglected_targets.csv contained 399 entries. Inspection revealed five duplicate systems — EE Aqr, SX Crv, V839 Oph, V2150 Cyg, and SV Equ — each appearing twice as a consequence of the Kreiner (2004) catalogue itself listing independent period solutions for the same object. In each case, the entry carrying the greater number of significant decimal places in the orbital period was retained as the more precise (and therefore more recent) solution, and the coarser entry was removed. After deduplication the working list comprised 394 unique eclipsing binary systems.

A triage file (triage_neglected_targets.csv) was then produced, sorting all 394 targets by TESS sector count in descending order and annotating each entry with its GCVS morphological category (EW, EW+, EB, EB+, or SD) and a priority tier (High: ≥5 sectors; Medium: 2–4 sectors; Low: 1 sector). Of the 394 systems, 114 qualified as High priority. The subset of 65 systems observed in six or more TESS sectors was identified as the primary working sample for detailed analysis, offering the most extensive photometric baselines and the greatest sensitivity to period changes in O–C residuals.

These 65 systems were distributed across eight processing batches, each containing eight stars with the exception of the final batch, which contains nine. Batch membership was determined by three criteria applied in order: (1) morphological category, grouping contact systems (EW and EW+) in batches 1–5, shorter-period detached systems (EB) in batches 6–7, and semi-detached and subgiant-contact systems (SD and EB+) in batch 8; (2) the presence in each batch of at least one high-sector "anchor" star to provide a well-constrained reference light curve; and (3) similarity of orbital period within a batch, so that initial PHOEBE 2 parameters — in particular the mass ratio prior and the fillout factor seed for contact configurations — remain physically consistent across the set.
