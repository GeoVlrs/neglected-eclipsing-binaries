Post-acquisition quality audit of the Script 02 light curves revealed an anomaly in the NU Cyg data product. While the remaining seven targets in the first processing batch exhibited eclipse amplitudes consistent with their EW/EB classification (28–74%), the cleaned light curve for NU Cyg showed a flux variation of only 0.04% peak-to-peak over a 24.9-day baseline, with a root-mean-square scatter of 0.008% and a constant per-point flux uncertainty of 0.000050 — characteristic of a quiet photometric standard, not an eclipsing binary.

Inspection of the FITS primary header identified the downloaded object as TIC 195744427 at coordinates RA = 314.29°, Dec = 41.17°. Cross-referencing this against the SIMBAD astronomical database confirmed that TIC 195744427 corresponds to ν Cygni, the Bayer-letter designation for a V = 3.94 magnitude A0IIIn giant — a non-variable star unrelated to the target. The root cause was a name-resolution collision within the lightkurve/SIMBAD resolver: the query string "NU Cyg" was matched to the Greek letter designation ν Cygni in preference to the variable star identifier V* NU Cyg. The true eclipsing binary, catalogued under TIC 169936511 at RA = 297.91°, Dec = 39.12°, lies 12.67° from the downloaded position. The same collision had propagated silently through Script 01, which confirmed TESS coverage for NU Cyg based on the bright Bayer star rather than the actual target.

To resolve the misidentification and prevent recurrence across the full 393-target sample, a TIC enrichment step was applied to all target catalogue files. For each star, its coordinates were retrieved from SIMBAD via a batch name query — which correctly resolves variable star designations through the "V*" prefix system — and the nearest entry in the TESS Input Catalog was then identified through a 30-arcsecond positional cone search of the MAST TIC catalogue. This two-step procedure is robust against Bayer-letter collisions because SIMBAD's variable star records are keyed to the IAU variable star designation rather than the Greek-letter assignment. The resulting TIC identifiers were written as a new tic column in all nine target CSV files. Script 02 was subsequently modified to construct MAST search queries from the TIC identifier directly — as the string "TIC <id>" — when one is available, bypassing the SIMBAD name resolver entirely. A third fallback pipeline was also added to the download hierarchy: in cases where neither the SPOC nor the TESS-SPOC FFI product exists for a given target, the script now attempts a download from the Quick Look Pipeline (QLP), a community-produced FFI photometry product available for targets outside the SPOC priority list. For NU Cyg specifically, the correct TIC 169936511 has no SPOC coverage but is present in QLP from Sectors 14 through 82; the most recent product (Sector 82, 200-second cadence) yields a light curve of 10 766 data points with a 33% eclipse amplitude, confirming that the correct eclipsing binary has been recovered.
